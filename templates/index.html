OCBC SME · pre-qualification demo

A conversational pre-qualification agent for OCBC's SME loan products

This demo maps a business to a Singapore SSIC code → finds an OCBC SME product that fits → checks eligibility on years in operation, revenue and loan amount → presents the outcome with an audit trail. Read the source on GitHub or the eval results.

Under the hood: four tools, 17 scripted evals, and a deterministic human-in-the-loop wrapper that intercepts illegal categories, foreign entities, advice-seeking, and other hard cases before the model runs.

Tips. Click a persona below the chat input to start with a sample business — it pre-fills your first message; edit or send as-is. The agent will ask you for anything it needs. The right-rail trace panel shows every tool call, every reasoning step, and any escalation the deterministic wrapper fires. Click reset above the chat to start a new conversation. Switch voice between OCBC-formal and conversational to see the same decision rendered in different brand voices.

Disclaimer: this is a portfolio demo running on mock product data. Real terms come from OCBC's credit assessment, not this chatbot.
